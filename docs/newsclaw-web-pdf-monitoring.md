# NewsClaw P5 网页/PDF 变化监控

P5 解决一个具体问题：重要网页或 PDF 更新以后，不让用户重新从头阅读，而是保存每个版本，只提示正文真正改变的部分，并把变化接入既有事件档案。

## 产品边界

- 监控对象必须由用户主动添加，且是公开 HTTP(S) 网页或 PDF。
- 它不是新闻源，不进入推荐池，不替代 Tushare/RSS，也不是通用网页爬虫。
- 首次成功读取只建立基线；只有后续规范化正文变化才创建事件变化和消息。
- 判断不调用 LLM 或 Tavily，不读取/修改五层画像和 P4 个人记忆。
- 用户名称、备注和关注点只是展示信息，不能改变客观差异结果。

## 后端链路

```text
创建目标和 document_monitor 事件（同一事务）
  → 独立调度器领取到期检查（持久租约 + single-flight）
  → 每次跳转解析公网地址，并把连接固定到同一个已验证 IP
  → 有界下载 HTML/PDF
  → 本地抽取、规范化和噪声过滤
  → 原始哈希 + 正文哈希分层判断
      ├─ baseline：保存 V1，不通知
      ├─ unchanged：只完成检查
      ├─ noise_only：留原始变化审计版本，不通知
      ├─ meaningful：版本 + diff + 事件变化 + 消息（同一事务）
      └─ failure：安全错误 + 有界重试 + 最终需要处理
```

数据表为 `web_monitor_targets`、`web_monitor_checks`、
`web_monitor_snapshots`、`web_monitor_diffs`、
`web_monitor_notifications` 和 `web_monitor_commands`。数据库 schema 为 v9，
迁移只新增表和索引，不改写 P1–P4 记录。快照和差异不可变；删除目标是软删除。

## 安全与资源上限

- 只允许 HTTP(S) 80/443；拒绝 URL 凭据、localhost、单标签主机、`.local`、`.internal`、私网、回环、链路本地和保留地址。
- 每个重定向都重新解析 DNS，连接固定到本轮已验证的公网 IP，同时保留原域名用于 Host/TLS 校验；实际 socket 对端还必须与该 IP 一致。拒绝 HTTPS 降级。
- HTTP 客户端不信任环境代理，不继承 Cookie/Authorization，不执行脚本或表单。ETag、Last-Modified 和响应 Cookie 不会被带到另一个域名。
- 最多 5 次重定向；整次抓取最多 30 秒；HTML 原始正文最多 10MB，PDF 最多 50MB；PDF 最多 1000 页。客户端只请求未压缩响应并拒绝服务器强制返回的压缩内容，防止解压炸弹在计数前占满内存。PDF 在独立子进程解析，20 秒超时会直接终止该进程，不让异常文档拖住后台。
- 全局最多并行检查 3 个目标，同一监控入口域名最多并行 1 个，避免用户一次添加多条同入口监控后反向压垮对方网站。若不同入口后来重定向到同一站点，仍受全局 3 路上限约束，不能把它夸大成“最终网站严格单路”。
- 加密、损坏、无可抽取文字的扫描 PDF 会显示明确安全错误，不伪装成无变化。
- 当前正式 8430 的 Python 运行形态已启用安全 PDF 子进程；未来若制作冻结式单文件安装包，必须把该 worker 一起打包，否则系统会明确拒绝 PDF 解析，而不是退回不可中止的线程。

## 一致性和重试

- 同一目标只能有一条运行中检查；手动检查会加入已有后台检查。
- 每次领取写入 lease token；过期 owner 即使晚完成，也不能覆盖新 owner 的结果。
- 失败按 1m、5m、30m、2h、6h 退避，第六次或不可重试错误进入 `needs_attention`。
- 变化、失败和恢复通知是持久数据库行。`delivered/read/dismiss` 均携带稳定 request ID；同 ID 用于不同动作会返回冲突。
- 事件中的 `effective_at` 表示本机观察到文档变化的时间，不冒充正文所述政策或公告的法律生效时间。

## 用户入口

- 桌面/窄屏 Web：内容库的“网页监控”，支持添加、立即检查、暂停/继续、软移除、折叠版本和进入现有事件档案。
- 消息：复用既有抽屉，持久显示正文变化、失败和恢复。
- DSH：内容库紧凑监控页；Agent Bridge 新增 7 个管理/历史/消息工具，并保留 2 个 Tavily 按需研究工具，总计 31 个工具。
- 浏览器扩展：只向正式 `newsclaw-api` 读取未读数并打开本机监控页；无目标站点权限。
- CLI：`newsclaw monitor list/add/check/pause/resume/remove/notifications/read`。

## 验收重点

1. 普通产品模式不注册 P5 路由、不启动 P5 调度器。
2. 第一次成功抓取没有事件变化和通知。
3. 仅页面噪声变化不通知；数字、否定词和状态词变化不能被噪声规则吞掉。
4. 真变化只产生一个快照、一个 diff、一个事件变化和一个通知。
5. 并发检查合流、过期 owner 被 fencing，模糊重试不重复写入。
6. SQLite `integrity_check` 为 `ok`，`foreign_key_check` 为空，旧表行数在迁移前后保持一致。
7. 8430 正式环境只使用真实空态/真实用户目标，不注入合成演示数据；8431 旧演示保持隔离。
