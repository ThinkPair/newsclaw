# NewsClaw / 新闻爪

**先懂你，再主动找真实新闻。**

📌 最新版本：**v0.1.0**

> 发布边界：NewsClaw 不使用上游 `openbiliclaw-v*` 聚合 Release 作为自己的更新或下载渠道；当前 GitHub 仓库仅用于私有源码托管。

NewsClaw 是一个只在本机运行的独立个性化新闻 Agent，用来每天为一个人整理真实新闻，提升宏观信息、投资理解和创作选题能力。它拥有自己的新闻来源、产品语义、数据和配置，不依赖其他产品运行。

> 2026-08-17 已完成本机正式切换：正式服务运行在 `http://127.0.0.1:8430`，使用独立数据库、独立 `NewsClaw` 开机启动项和 DSH 2.0.0 插件。开发调试仍使用 8431，不覆盖正式运行目录。

## 核心体验

- 每天从已授权的新闻 API 和官方/自定义 RSS 获取内容，不爬网页、不读 Cookie。
- 用“事件 → 偏好 → 觉察 → 洞察 → 灵魂”五层记忆从打开推荐、喜欢、不感兴趣、忽略、评论和对话中学习。收藏与稍后读只在本机保存，不会自动改变画像。
- 手工修改的画像始终高于 AI 推断；每条洞察保留证据、置信度和可删除性。
- 推荐理由回答“为什么适合你、可能影响链、后续观察点”，不输出买卖建议。
- 标题级、摘要级和正文级证据严格区分；AI 不得把标题伪装成读过全文。
- 单一来源失败只使系统进入降级，不会假装整体刷新成功。

## 新闻来源

首批只支持已形成明确契约的入口：

- Tushare `news`、`major_news`、`cctv_news`；
- 网站主动提供的 RSS/Atom；
- 用户自己添加的 RSS/Atom。

每条文章存储媒体、技术提供方、原文链接、发布/抓取时间、正文等级、内容哈希和时效状态。

## 四个客户端

- 桌面 Web：推荐、当前列表筛选、内容库、画像、对话、消息、Runtime 和完整设置。
- 手机 Web/PWA：同一数据库和画像，支持下拉刷新与在线/降级/离线状态。
- 浏览器扩展：只是新闻爪侧栏客户端，不注入新闻网站、不抓页面、不读 Cookie。
- DeepSeek Harness：真实尾部网格列，默认 380px，可调 280–560px，会话区至少保留 400px。

四端共用一个后端、SQLite 数据库、画像、推荐池、收藏和对话记录。

## 本地开发预览

```powershell
& .\scripts\run-newsclaw-dev.ps1 -Port 8431 `
  -RuntimeRoot "<private-runtime-directory>" `
  -SourceConfig "<existing-local-config.toml>" `
  -PythonExecutable "<python-with-project-dependencies>"
```

启动后打开 `http://127.0.0.1:8431/web`。凭据只保存在私有运行目录或环境变量，不写入源码、日志或 Agent 输出。

日常使用、功能和配置说明见 [NewsClaw 使用指南](docs/newsclaw-user-guide.zh-CN.md)；架构、数据合同和失败边界见 [NewsClaw 架构](docs/newsclaw-architecture.md)。

## 使用边界

- 默认仅供本人本机、非商业使用。
- Tushare 新闻权限与普通会员权限独立，启动时会逐接口验证。
- 以后如果公开、收费或展示第三方全文，必须重新取得机构和内容展示授权。
- 本版不做量化行情、券商接入、自动交易、网页爬虫或公网部署。
